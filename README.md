# ⚙️ OS CPU Scheduling Simulator & Visualizer

An enterprise-grade, highly interactive CPU Process Scheduling Simulator and visualizer built with Python, Tkinter, and Matplotlib.

---

## ✨ Features
* **Core Algorithms Implemented:**
  * First-Come, First-Served (**FCFS**)
  * Shortest Job Next (**SJN**)
  * Round Robin (**RR**) with dynamic Time Quantum slider.
* **Interactive Data Visualization:**
  * Real-time **Gantt Chart** timeline generation.
  * Individual process metrics: Waiting Time, Turnaround Time, and Finish Time.
  * System metrics: Overall Average Waiting Time, Average Turnaround Time, and **CPU Utilization %**.
* **Algorithm Comparison Mode:** One-click comparison view contrasting all algorithms side-by-side with best-performer highlights.
* **Modern GUI:** Cyber-inspired Dark Theme UI built with custom Tkinter components and resizable sidebars.

---

## 🛠️ Built With
* **Language:** Python 3.x
* **GUI Engine:** `tkinter`, `ttk`
* **Plotting & Analytics:** `matplotlib`, `numpy`
